# BK Tools — user guide

**[Open the app](https://alirezarajabi-dev.github.io/bk-tools/)**

Choose one of the six tabs. Files and form values remain in this page while you
switch tools. Refreshing/leaving can clear your working data; save outputs you
want to keep. Files are processed on your device, without an upload service.

## Images

1. Drop or choose a JPG, PNG or WebP image.
2. Choose output format, maximum width and quality where supported.
3. Select **Create preview**; compare appearance, dimensions and byte sizes.
4. Select **Download image**, then keep the output that works for you.

A result can be larger than its input; the tool says when it is. No upscaling.
PNG keeps transparency; JPG fills it with white. Metadata is not retained by
canvas encoding. This creates a still image, not an edited animation.

## Rates

1. Set currency, monthly expenses, take-home goal and billable hours.
2. Choose your income-tax reserve; it applies to revenue after listed expenses.
3. Enter project hours, buffer and any sales tax to add to the quote.
4. Review the hourly rate and breakdown; add a scope description.
5. **Copy estimate** or **Download TXT**.

Initial numbers are illustrative. This is a planning estimate, not an invoice
or market-rate recommendation. Currency changes the label, not the value; no
exchange conversion or country-specific tax rules are applied.

## Configs

1. Choose `.gitignore`, `Dockerfile` or `.dockerignore` and the project stack.
2. Set an entry file where applicable, then generate and edit the output.
3. Review image versions, ports and build assumptions for your actual project.
4. **Copy file**, or **Download ZIP** and extract the exact-named file.

Switching tools preserves edits. Selecting a new template replaces the editor.
For a Dockerfile choose a concrete runtime rather than a generic container.

## Signatures

1. Replace the example name, role, company and contact details.
2. Choose an accent and review the live signature.
3. **Copy signature** for styled content, **Copy HTML** for code, or download HTML.
4. Paste into your email client's signature settings and test the result there.

No email is sent by BK Tools. Pasting and final appearance depend on the client
and browser; Gmail/Outlook rendering is not certified by a browser preview.

## Data

1. Open UTF-8 CSV/JSON, or **Try an example**.
2. For CSV, choose whether the first row is a heading and adjust the separator
   if automatic detection does not match the file.
3. Search. Click a column to sort ascending, descending, then clear sorting.
4. Pick 25/50/100 rows per page and download the filtered CSV or JSON.

Spreadsheet-safe CSV export is on by default: formula-like text receives an
apostrophe prefix. Disable only when you intentionally need raw values.
Long table cells are shortened for display; JSON downloads retain full nested
records. File/table limits and parsing errors are shown instead of dropping rows.

## Licenses

1. Select MIT, Apache 2.0, GPL v3 or BSD 3-Clause.
2. Enter project, copyright holder and year/year range.
3. For GPL, explicitly choose version-3-only or permission for later versions.
4. Read the full text and notice; the official source link is provided.
5. **Download license ZIP**, then extract `LICENSE` and `COPYRIGHT-NOTICE.txt`.

MIT/BSD placeholders are filled. Apache/GPL text remains unchanged; your project
information goes into the separate notice. Keep applicable third-party notices.

## Finding saved files and installing

The requested filename is displayed. Check your browser's Downloads or the
location chosen in the native save/share sheet. Compatible iPhones/iPads use
the file share sheet. In local framed previews, an extra **Save file** bar keeps
the preview open while saving.

Optional Home Screen/Desktop installation uses the **BK + Tools** icon and short
name **BK Tools**. A normal browser tab works without installation. Installation
options vary by browser; offline caching is not included.
